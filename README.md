# Bence Gyurus - Portfolio

A modern, bilingual (English & Hungarian) personal portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion. 

## Features
- **Bilingual**: Fully localized in English and Hungarian using custom dictionaries.
- **Modern UI**: Clean design, fully responsive layout.
- **Tech Stack**: Highlights the infrastructure, networking, and programming tools I use (e.g., Python, C++, TypeScript, Docker, Linux, Proxmox, GitOps).
- **Projects & Infrastructure**: Features my Math Practice Platform and detailed diagrams of my personal HomeLab.

## Development
To run this project locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
